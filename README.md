# GudangSoftware — WooCommerce Store

GudangSoftware sedang dimigrasikan dari portal alat HTML gratis menjadi **toko produk digital berbasis WordPress + WooCommerce**.

## Hasil pengembangan baru

- [Download tema WooCommerce siap unggah](woocommerce/gudangsoftware-store.zip)
- [Source code tema](woocommerce/gudangsoftware-store/)
- [Panduan migrasi lengkap](woocommerce/README.md)
- [Ide katalog yang masih draft](woocommerce/katalog-rencana.csv)

**Penting:** WooCommerce harus berjalan di hosting WordPress dengan PHP dan database, bukan GitHub Pages. Selama migrasi, file website statis 27 tools masih tersimpan di root untuk mencegah downtime dan menjadi cadangan. Domain tidak otomatis berubah hanya dengan commit ini. Tema tidak memuat skrip iklan lama. Produk, harga, pembayaran, dan file unduhan harus disiapkan melalui dashboard WooCommerce sebelum penjualan live.
